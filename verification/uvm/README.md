## Prerequisites

Before running the UVM simulation flow, ensure you have downloaded and set up the UVM library:

* **Official Release:** Get the patched uvm libaries from the verilator repository
```bash
   git clone https://github.com/verilator/uvm.git uvm-verilator
```   
* **Environment Variable:** Set `$UVM_HOME` pointing to your extracted UVM directory:
  ```bash
  export UVM_HOME=/path/to/uvm-verilator
  ```
