## Prerequisites

Before running the UVM simulation flow, ensure you have downloaded and set up the UVM library:

* **Official Release:** [Download UVM (Universal Verification Methodology) - Accellera Systems Initiative, v1.2](https://www.accellera.org/downloads/standards/uvm)
* **Target Version:** UVM 1.2
* **Environment Variable:** Set `$UVM_HOME` pointing to your extracted UVM directory:
  ```bash
  export UVM_HOME=/path/to/uvm-1.2
  ```
